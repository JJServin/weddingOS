# Testing guide

Run `npm install`, then `npm run lint`, `npm run test`, `npm run build`, and `npm run test:e2e`. Playwright starts Vite automatically. For manual review, test both modes, enter a distinctive private phrase for Partner A, switch to Partner B and confirm it is absent, approve one item, review the bridge, pause/resume, capture shared learning and verify the record excludes private integration.

At 320–375px, check that controls remain reachable, textareas do not zoom, stage labels scroll, focus is visible and primary flow is keyboard operable.
