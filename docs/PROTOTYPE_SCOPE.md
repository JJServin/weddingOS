# Prototype 0.1 scope

Included: the complete static Encounter One flow, Core and Christ-Centered modes, two simulated local partners, together mode, deterministic approved-content bridge, pause/resume, shared record, feedback, responsive UI and local persistence.

Excluded: Encounter Two, production authentication/privacy/security, Firebase or any backend, AI, cloud deployment, payments, analytics and sensitive data. The single-device simulation exists only to validate the experience.
